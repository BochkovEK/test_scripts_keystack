Создать скрипт диагностики базовых сервисов Openstack
1) состояние контейнеров на узлах
2) keystone
3) mariadb (galera)
4) rabbitmq

openstack-diag/
├── ansible/
│   ├── ansible.cfg             # настройки Ansible: timeout, forks, gather_facts
│   └── playbooks/
│       └── containers.yml      # плейбуки диагностики
├── src/
│   ├── __init__.py
│   ├── config.py               # загрузка и управление конфигурацией
│   ├── default_config.py       # системные настройки (архитектура проекта)
│   ├── logger.py               # настройка логирования
│   └── ansible_runner.py       # запуск Ansible плейбуков
├── reports/                    # генерируемые отчёты (создаётся автоматически)
│
├── inventory.ini.template      # шаблон инвентори
├── inventory.ini               # пользовательский инвентори (в .gitignore)
├── config.yaml                 # пользовательский конфиг: paths, nodes, services, thresholds
├── diagnose.py                 # основная точка входа
├── test_config.py              # тесты конфигурации
├── README.md                   # документация
├── .gitignore                  # inventory.ini, reports/, логи
└── requirements.txt            # зависимости Python

pip install ansible-runner
pip install ansible

logger.py

Основной логгер - для diagnose.py, config.py
- Консоль: INFO
- Файл: DEBUG (diagnostics.log)

Ansible логгер - для ansible_runner.py
- Консоль: DEBUG
- Файл: DEBUG (ansible.log)

Report логгер - для отчетов
- Файл: INFO (reports.log)
