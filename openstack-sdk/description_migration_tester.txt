Миграция командами CLI
source_host="";
target_host="";
# Migration all VMs from source_host to target_host
for vm_id in $(openstack server list --all-project --host $source_host --status ACTIVE -c ID -f value); do
    echo "Migration VM $vm_id to $target_host..."
    openstack server migrate --live-migration --host $target_host $vm_id
done

О скрипте
OpenStack Live Migration Test Script - инструмент для тестирования производительности live-миграции виртуальных машин между гипервизорами в OpenStack.

Основные ключи запуска
    Конфигурация миграции
    --hypervisors - список гипервизоров через запятую для циклической миграции (обязательный)

    --max-parallel - максимальное количество параллельных миграций (-1 = без ограничений)

    Параметры выполнения
    --duration - общая длительность теста в секундах

    --migration-timeout - таймаут для одной миграции в секундах

    --full-circle FULL_CIRCLE - выполнить миграции всех ВМ по указанным гиперам указанное количество циклов

    Конфигурация OpenStack
    --cloud - имя облака из clouds.yaml

    --interface - интерфейс эндпоинтов OpenStack

    Повторные попытки
    --retry-attempts - количество попыток для неудачных миграций

    --retry-delay - задержка между попытками в секундах

    Вывод и логирование
    --log-level - уровень логирования (DEBUG, INFO, WARNING, ERROR)

    --output-format - формат вывода результатов (table, json, text)

    --results-file - файл для сохранения результатов

Альтернатива: переменные окружения
    Все параметры можно задать через переменные окружения:

    MIGRATION_TEST_HYPERVISORS - вместо --hypervisors

    MIGRATION_TEST_DURATION - вместо --duration

    И другие с префиксом MIGRATION_TEST_

Запуск:
    # Базовый запуск
python ./migration_test.py --hypervisors "hypervisor1,hypervisor2,hypervisor3" --duration 360

    # С параллельными миграциями (by cycle)

# Если
cat /etc/kolla/nova-compute/nova.conf |grep max
max_concurrent_live_migrations = 5
python ~/test_scripts_keystack/openstack-sdk/migration_tester.py \
    --hypervisors cdm-bl-pca05,cdm-bl-pca06,cdm-bl-pca08 \
    --max-parallel 5 --full-circle 1

    # С параллельными миграциями (by duration)
python ./migration_test.py --hypervisors hv1,hv2 --max-parallel 5 --duration 7200

    # С подробным логированием
python ./migration_test.py --hypervisors hv1,hv2 --log-level DEBUG --output-format json

    # Короткий тест (5 минут) с 2 гипервизорами
python migration_tester.py \
    --hypervisors "compute01,compute02" \
    --duration 300 \
    --migration-timeout 120 \
    --max-parallel 1 \
    --log-level INFO \
    --output-format table

    # Для отладки без реальных миграций:
python migration_tester.py --output-format json

    Примечание:
        --max-parallel 2 (значение по умолчанию) Империческим путем установлено что число 2 является оптимальным

# Примеры переменных окружения
    export MIGRATION_TEST_HYPERVISORS="compute01,compute02"
    export MIGRATION_TEST_DURATION=300
    export MIGRATION_TEST_LOG_LEVEL=DEBUG
